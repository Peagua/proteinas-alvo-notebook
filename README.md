# Notebook do pipeline de proteinas alvo
Este projeto junta todos os scripts e passo a passo do projeto original em apenas um notebook Jupyter, com algumas melhorias e adaptando para o uso com dados de Bioassays de cada composto no PubChem, ao invés dos dados em "Proteins". O script em bash ainda precisa ser executado pelo terminal.

O passo a passo está bem detalhado no notebook, mas caso tenha alguma dúvida ou insegurança, basta rodar cada script original do outro repositório individualmente.
